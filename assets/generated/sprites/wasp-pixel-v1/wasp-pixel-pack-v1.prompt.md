# Pixel wasp content pack v1

One 4×2 production sprite sheet on a saturated green removal background, with
eight complete mechanical wasp silhouettes: wing-up, wing-level, wing-down,
bank, dive-lock, committed dive, recovery brake, and hit recoil. The creature
uses one connected black-metal body mass, acid-green armour, silver articulated
blade wings, and one amber eye. It is side-facing, high-contrast, readable at
24–42 display pixels, and uses deliberately stepped pixel clusters rather than
a smooth high-resolution painting downsampled at runtime. Cells have generous
separation and no labels, effects, shadows, cropped limbs, or loose props.

The source plate is preserved beside the runtime crops. The runtime atlas is
128 pixels per cell so the generated pixel clusters land near one texel before
the FAR camera performs its final display-scale minification.
