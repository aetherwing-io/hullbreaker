# T-019 evidence: where a reflex policy stops

Committed evidence for `docs/playtests/2026-08-victory-box.md` — the finding
that no bot run reaches VICTORY, that the wall is wave gate 2 / scroll 140 of
415, and that the box has to be answered by an operator run.

Only the small artifacts are here. A full `report.json` is ~2 MB of per-tick
trace, and there were 49 of them; what is committed is each run's own
`summary.md` (written by `lib/report.mjs`) and the `analyze-run.mjs` output
derived from the trace, which is where every number in the finding comes from.

| path | what it is |
| --- | --- |
| `all-runs.md` | one row per run, generated by `analyze-run.mjs --brief`: the 49-run corpus the finding argues from, plus the four re-verification runs made when the review corrections landed (listed apart, not folded into the medians) |
| `six-face-spaced-run/` | a run of the policy this task ships, made from the committed script file itself (52.0 s, 10 kills, dead in gate 2 — the 8th run of that ruleset, inside the 50.2–55.1 s band the other seven measured) |
| `six-face-aimed-run/` | the same for T-018's shipped policy, the baseline it is measured against (SHIP-1: 49.8 s) |
| `gate2-cleared/` | **the one run in 49 that cleared wave gate 2** (J-3: 64.4 s, 21 kills, scroll 165, died heading for gate 3), plus `expJ-strafe.json`, the un-shipped `strafe`-lock variant that produced it — kept so the claim is reproducible even though the variant's median is no better than the shipped policy's |

Regenerate any of it:

```sh
cd <worktree> && python3 -m http.server 8771 &

cd tools/playtest
node run.mjs scripts/six-face-spaced-run.json --base-url http://127.0.0.1:8771 \
  --deterministic --stop-on-game-over --max-runtime-ms 145000 --out /tmp/spaced
node analyze-run.mjs /tmp/spaced > analysis.txt
```

Honesty: the harness is not run-to-run deterministic (see the README's
"Deterministic injection mode" — `--deterministic` fixes *when* input is sent,
not the browser's frame cadence). Survival times move ±6 s between identical
runs, which is why the finding argues from medians over 3–10 repeats and from
*which gate ended the run*, never from one run's decimals.
